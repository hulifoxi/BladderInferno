# 膀胱炼狱 · 极限尿压 - 转盘版 🎰

这是一个基于 HTML、CSS 和 JavaScript 的单文件网页游戏，灵感来源于x上的各种憋尿挑战。玩家通过旋转一个充满随机奖励与惩罚的轮盘，在不断累积的尿意压力下，测试并挑战自己的生理和心理极限。

---

## ✨ 主要功能

*   **动态转盘:** 使用 HTML5 Canvas 绘制的交互式转盘，随机抽取奖励或惩罚。
*   **回合制挑战:** 游戏分为准备阶段和多轮挑战阶段。
*   **计时系统:** 包含准备倒计时和每轮挑战间的等待倒计时。
*   **累积饮水:** 每轮需按规则饮水，水量逐渐累积，增加挑战难度。
*   **随机事件:** 转盘结果触发各种奖励（如短暂排尿、减少轮数）或惩罚（如增加轮数、特殊动作、额外饮水）。
*   **实时日志:** 记录游戏进程中的关键事件和玩家操作。
*   **胜负判定:** 根据完成轮数或宣告失败判定游戏结果。
*   **失败动画与惩罚:** 宣告失败后触发羞耻动画（扔东西）和醒目的惩罚流程展示。
*   **一次性特殊行动:** 提供一次性的“主动排尿”机会，但伴随后果。
*   **响应式UI:** 界面元素经过优化，风格统一，色彩和谐。
*   **单文件部署:** 整个游戏包含在一个 HTML 文件中，易于分享和运行。

## ⚙️ 游戏玩法

1.  **准备阶段 (90分钟):**
    *   点击“开始挑战”按钮启动90分钟准备倒计时。
    *   在此期间，玩家应排空膀胱，准备所需道具（足够的水、可选的控尿工具等），并调整好心态。
    *   可以点击“跳过等待”按钮直接进入挑战阶段。

2.  **挑战阶段 (多轮):**
    *   准备阶段结束后，游戏自动进入第一轮挑战。
    *   **每轮流程:**
        *   **饮水:** 根据指示喝下定量的水 (默认为 250ml)。
        *   **转动轮盘:** 喝水后，轮盘出现并自动旋转，随机抽取“奖励”或“惩罚”类型。
        *   **执行结果:** 根据轮盘指向的结果，执行相应的奖励或惩罚动作/效果。奖励可能包括短暂休息、排尿机会、减少总轮数等；惩罚可能包括特殊动作、额外喝水、增加总轮数等。部分奖励/惩罚有等级或累积效果。
        *   **等待:** 完成奖励/惩罚后，进入15分钟的等待倒计时。此期间可以点击“跳过等待”直接进入下一轮。
    *   **特殊行动 (挑战阶段可用):**
        *   **主动排尿5秒 (仅一次):** 点击按钮确认后可排尿5秒，但会增加总轮数并需要额外喝水。使用后按钮消失。
        *   **宣告失败 (失禁):** 点击按钮确认后，游戏立即结束，判定为失败。触发失败动画和惩罚展示。

3.  **游戏结束:**
    *   **胜利:** 成功完成所有预定轮数（总轮数可能因奖励/惩罚而增减）。触发胜利庆祝效果（彩带）。
    *   **失败:** 在挑战阶段主动点击“宣告失败”按钮。触发失败动画和惩罚弹窗。

## 🚀 如何开始

1.  **克隆仓库:**
    ```bash
    git clone https://github.com/hulifoxi/BladderInferno.git
    ```
    或者直接下载 `index.html` 文件。

2.  **打开文件:**
    使用现代的网页浏览器（如 Chrome, Firefox, Edge）打开 `index.html` 文件即可开始游戏。无需任何服务器或额外依赖。
